# 🌱 Salon Bio

**Salon Bio** est un **projet d'étude** réalisé pendant ma formation.  
L'objectif n'était pas de créer une application complète et finie, mais plutôt de **découvrir et expérimenter** différentes technologies pour comprendre comment elles fonctionnent ensemble.  

Le projet reste volontairement **simpliste** et **non terminé**, mais il montre la mise en place d'une **API RESTful** et les bases d'une application web connectée à une base de données.

---

## 📚 Objectifs du projet

- Apprendre à créer une **API RESTful** (CRUD : Create, Read, Update, Delete).
- Manipuler **EJS** pour générer des pages dynamiques côté serveur.
- Connecter une application à une **base de données MongoDB**.
- Comprendre le lien entre **front-end**, **back-end** et **base de données**.
- Réaliser un projet pédagogique pour progresser, **sans viser un produit finalisé**.

---

## 🛠️ Technologies utilisées

- **Front-end** :  
  - HTML  
  - CSS  
  - [EJS](https://ejs.co/) (Embedded JavaScript Templates)

- **Back-end** :  
  - Node.js  
  - Express.js  

- **Base de données** :  
  - MongoDB (NoSQL)  
  - Mongoose

---

## 📂 Fonctionnalités (simples et incomplètes)

- 📝 **CRUD basique** sur les produits :  
  - Ajouter un produit  
  - Afficher les produits  
  - Modifier un produit  
  - Supprimer un produit  

- 🗂️ **Catégories** : possibilité d’associer un produit à une catégorie (via MongoDB).  
- 🖥️ **Pages dynamiques** avec EJS (rendu côté serveur).  

⚠️ **Attention :**  
Le projet n'est pas finalisé et ne couvre que les bases.  
Il a été conçu uniquement dans un **but pédagogique**.
